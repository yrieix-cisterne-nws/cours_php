# Projet PHP

Ce petit projet contient trois scripts PHP d'exemples pour apprendre les bases de PHP.

## Fichiers

- `date.php` : affiche si une date de sortie est bientôt (moins de 31 jours) ou non.
- `film.php` : calcule les bénéfices et le retour sur investissement d'un film, puis affiche une appréciation (`Blockbuster`, `Rentable`, `Modeste`, `Flop`).
- `naissance.php` : affiche des informations de base (age, prénom, année de naissance) et compare deux âges.

## Dépendances

- PHP installé (version 8.x recommandée).
- Un serveur local (ex : built-in `php -S localhost:8000`, XAMPP, WAMP, etc.).

## Installation

1. Clonez le dépôt (remplacez l’URL par l’URL du dépôt GitHub) :

```bash
git clone https://github.com/yrieix-cisterne-nws/cours_php.git
```

2. Entrez dans le dossier du projet :

```bash
cd cours_php
```

3. Lancez le serveur PHP intégré :

```bash
php -S localhost:8000
```

4. Ouvrez votre navigateur :

- `http://localhost:8000/date.php`
- `http://localhost:8000/film.php`
- `http://localhost:8000/naissance.php`
